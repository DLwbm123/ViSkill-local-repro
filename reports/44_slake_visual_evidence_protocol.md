# SLAKE 区域技能卡与兼容检索的视觉增益验证协议

2026-10-25，模型调用前冻结。用户要求改进技能卡和检索，再验证一轮真正的视觉增益，避免照搬参考答案。

## 假设与改动

上一轮提示包含完整源问答，真实卡相对无参考的净增益集中在源答案与当前答案相同组，四道受损题均沿用了源答案。新轮检验：隐藏源问答，提供训练标注支持的定位和局部细节，按问题意图与目标严格匹配并允许拒绝检索后，相关视觉内容是否有独立收益。

- 训练来源为官方 train 的区域标注与问题；按源图、解析出的意图、目标去重，形成323条、141张训练图的静态库。没有把一次问答正确冒称临床策略验证。
- 卡片672×336，左为带一个原标注框的上下文，右为该区域加15%边距的放大图。原始框可能包含邻近结构，不宣称精确分割或经过临床复核。卡上没有文字、答案、坐标或侧别标签。
- 文字只提供从当前问题解析的目标和任务步骤，强调只根据当前图判断存在、数量、位置或形态。源问题和答案不进入卡片或提示；解析和检索接口拒绝查询金标及源答案字段。
- 候选必须意图与目标相同、有目标区域及同图不同实体的非重叠对照区域，并至少有两张不同训练图可用。评分为0.7原有CLIP图像余弦＋0.3问题token Jaccard；不读取查询模态金标、问题类别或ROI。复用旧546张图的固定图像特征，不再进行特征训练。
- 检索阈值为训练库留一图最高分的10%分位与0.75的较大值：实际0.9511365860700607，276条训练留一图记录。低于阈值或没有兼容证据时不提供卡片。

## 数据与五种条件

官方英文validation中六类视觉问题共695道，排除上一轮已使用96题后有599道。新题仍来自此前已观察的96张验证图，**不是未见图像测试，也不读取test.json**。

覆盖面板每图固定随机选一道新题，共96题，其中18题达到检索条件。机制面板只依据无答案输入和冻结检索确定，每图最多两道，共64题、40张图；其中源隐藏答案不同于查询金标者21题。两面板去重为145题、96张图，固定两次引擎初始化，每题五条件，总计1450次生成。面板、检索和顺序均在模型调用前保存，不根据输出更换。

| 条件 | 参考文字 | 参考图 |
|---|---|---|
| N | 无 | 无 |
| V | 当前问题派生的任务步骤，无源问答 | 正确源区域上下文与放大 |
| Blank | 与V相同 | 同尺寸全白 |
| Text | 与V相同 | 无 |
| Wrong | 与V相同 | 同一源图中不同实体且IoU≤0.1的原标注区域及放大 |

V、Blank、Wrong具有相同提示IDs和图像grid，运行时逐题逐重复检查。Wrong不是随机换病例，它保留同源图和版式，改变框选区域与放大内容。没有匹配卡时五条件均回退到无卡输入。CPU已核对两个生产格式样例的图像、输入边界和提示；尚未开始GPU生成。

## 判定与分析

使用未修改b0，greedy T0、top_p1、输出最多64tokens；引擎seed42、43分别覆盖全部条件。它们检查引擎重启后的重复性，不是独立训练seed；本轮0次参数更新。准确率沿用原规范化精确匹配，不事后给予同义词或单复数加分。

事前视觉证据门要求：

1. 机制面板至少40题、30张图。
2. V相对Blank、Text均在两次重复中为正；重复取平均后，以图像为簇的10000次bootstrap，其两个95%区间下界均严格大于0。
3. V相对Wrong在两重复中均为正，整体V相对N不下降。
4. 源隐藏答案与当前金标不同的预定分层至少20题，V相对Blank和Text的平均差均为正，而且错误沿用源答案次数不超过Blank。

否则报告视觉增益证据不足。必须完整报告覆盖面板、机制面板和合并面板，所有改善/受损、角色分项、错误源答案匹配与逐重复变化。该门检验这版区域证据原型，不作为完整SLAKE、患者泛化、临床获益或完整ViSkill学习闭环的证明。已观察的验证图和本轮新题不能再称为盲测。
