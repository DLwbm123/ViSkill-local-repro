# SLAKE 正负配对视觉参考最后一次限额验证协议

2026-10-25，模型调用前冻结。用户要求根据Pro建议继续实验；结合既定医学目标，本轮执行医学静态参考路线的最后一次限额验证，不自动转回FrozenLake或进入训练。

## 假设与研究范围

前两轮未建立视觉增益，第二轮仅流程文字已使准确率下降；所选存在性来源全为正例，金标No题的误答Yes上升。本轮检验：去除手写流程与警告段落，使用同模态、同解剖部位的正负参考对后，正确参考像素是否提供超过无参考、相同文字、空白、错误区域及错配标签的实用净收益。

主要对象为单目标存在/不存在判断，仍是冻结模型的视觉证据原型，不称为学到临床程序性技能。不会用已有96张验证图充当新图测试。两轮旧结果及故障均保留。

## 仅训练集来源核验

来源规则与候选池先于GPU调用和测试输入准备冻结：

- 仅使用train显式Yes/No存在性问题，解析出一个目标；排除侧别、正常性、数量、比较和描述性问题。相同源图/目标的存在性标签冲突则排除。
- 正例要求目标原标注框及同图不同实体、IoU≤0.1的对照框。负例必须有显式No，且不与目标区域标注或存在性Yes冲突；绝不把缺少框单独当作不存在。
- 按目标、训练模态、训练解剖部位组成匹配组，每类预先随机抽至多8例，不根据后续输出补充候选。CPU已固定7组、84个候选：44个Yes、40个No。
- 每个候选只做一次原b0无参考回答，答复与训练标签一致才准入；每组取相同数量的正负例，至少每类2例。按原候选顺序截取，不依模型置信度挑选。
- 来源门要求至少3个匹配组、每类至少12张不同源图、至少20条训练留一图校准查询。不满足则停止，不打开测试输入。

这是训练标注内部一致性与基础模型复核，不是独立临床认证。模型同意金标仍不能证明医学真实性，这一限制必须保留。

## 检索和中性参考

检索只接收qid、问题和图像，先要求同目标与存在性意图。每个候选匹配组内分别选图像余弦最高的正例和负例，用两者较小的相似度作为对分数，再选择最高组。正负来源始终同模态、同部位；查询模态/部位金标、答案与查询ROI不进入检索。

阈值为训练留一图最高对分数10%分位与0.85的较大值，来源库冻结后确定。复用原450张训练图的固定CLIP图像特征，测试图仅编码一次，不进行特征拟合。

每张参考672×336，左为完整源上下文，右为加15%边距的局部图。正例使用原目标框；负例将正例框按源尺寸比例映射为搜索窗口，它不是经过标注的阴性病灶区域。Wrong改用同图不同实体框及其映射窗口。

提示保持原短答案system，仅含参考目标名、一个present和一个absent的平衡标签、当前图与当前问题，不再添加手写判断流程。原始源问答不展示。平衡标签属于训练来源示例信息，不是查询金标；文字和空白对照保留同样标签。

| 条件 | 平衡标签 | 参考视觉内容 |
|---|---|---|
| N | 无 | 无 |
| V | 有 | 正确区域正例与核验负例 |
| Blank | 与V相同 | 两张同尺寸白卡 |
| Text | 与V相同 | 不放参考图 |
| Wrong | 与V相同 | 同一对源全图，不同实体区域与对应搜索窗 |
| Swap | 与V相同 | 交换正负两张完整卡，保留标签位置，故对应错误 |

Swap专门检查像素与标签对应，而Wrong检查局部框选；两个对照回答不同问题。V/Blank/Wrong/Swap的提示IDs和图格必须一致。参考正负展示顺序在题间平衡，同题第二次重复反转，避免固定抄前一条或后一条标签。

## 新图确认与答案隔离

来源门通过后才准备官方英文test输入。输入准备只访问问题、图像、语言、任务元数据和qid，不访问答案字段；不打开查询区域标注。测试图ID必须与之前450张train和96张validation图完全不交叉。所有生成完成后，由独立关闭评估器首次访问答案字段，统一计算原精确匹配分数。若预检停止，不读取确认答案。

- 覆盖面板：每张新图均匀抽一道可解析的存在性题；无此类题时抽一道视觉题并回退无参考。它描述预先定义的存在性任务覆盖，不代表全部SLAKE问答覆盖。
- 机制面板：每图最多2道达到冻结检索规则的存在性题，只依据输入和来源相似度选择。
- 生成前覆盖门：机制至少48题、32图、3个目标，覆盖面板至少30%能检索。若不满足，正常记录可行性停止，不修改规则或补样本。
- 两面板合并不超过288题。每题六条件、两次独立引擎初始化seed42、43。加上来源核验，最多4000次生成请求。

T0、top_p1、最多64输出tokens；查询最长边512。仍使用未修改Qwen2.5-VL-3B b0，0参数更新。两重复属于推理重启重复性，不是独立训练seed。

## 预定效果与安全门

在机制面板上，以下条件须同时满足：

1. V−N至少+5个百分点，V−Text与V−Blank分别至少+3个百分点；三个按图像聚类bootstrap的95%下界均严格大于0，且每次重复差值均为正。
2. V−Wrong和V−Swap平均均为正，且每次重复不为负。
3. 至少15道金标Yes和15道金标No，机制题没有意外非二元标签；V的假阳性率和假阴性率相对N各最多增加5个百分点。
4. 覆盖面板V−N不下降，不能仅靠条件子集掩盖总体退步。

另报告展示顺序、类别、目标、拒绝检索、全部改善/受损，以及跨重复稳定的视觉独有受益案例。不同标签均已作为参考呈现，不能再使用“与单个源答案不同”分层代替正负类别检验；错误匹配也不直接作为复制的因果证据。

未通过、支持不足或覆盖不足，均不足以支持该版本视觉价值，按本次授权结束静态医学参考路线，不追加prompt、模型、数据集搜索或训练。通过也只构成该任务和新图上的有限正信号，后续学习实验需另立协议。
